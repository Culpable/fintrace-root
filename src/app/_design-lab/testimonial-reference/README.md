# Testimonial reference

This unrouted design-lab folder preserves the retired `/testimonial/` review page.

It contains the approved combined Nick Brookes wording in three retired portrait-position layouts, the selected production frame and the exact single-paragraph `origin/main` reference.

To review or restore these layouts, use `page.tsx`, `testimonial.css`, `ClientVoice.tsx`, `FramedClientVoice.tsx` and `testimonial.ts`. Because the parent folder starts with `_`, Next.js excludes this page from routing and static export.
